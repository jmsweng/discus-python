# Monte Carlo disorder models with DISCUS MMC (Package D, Features 15–17)

`discuspdf.mc` writes, runs and reads DISCUS 6.23.01 `mmc` (multiple-energy Monte Carlo) simulations from
Python. You describe the run with an `MCConfig`, read the generated macro, run it with `MCRunner`, and get an
`MCResult` with the final structure, DISCUS's feedback history, and an independent measurement of every target.
The commands come from the DISCUS source (`docs/MC_FACTS.md`); the engine probe
([`d_mc_probes/RESULT.md`](../benchmarks/discus_6_23_01/d_mc_probes/RESULT.md)) ran swap, shift and swdisp moves,
one target of each type and kT ≠ 1. The opt-in live test (`tests/test_mc_live.py`) runs macros generated by
`MCConfig`: they reproduce four probe runs exactly, and two runs with several targets, neighbourhoods and moves,
a two-site cell, `local`/`slocal` pairing and kT = 0.5 complete with every target measured independently
(evidence in `d_mc_probes/evidence/live_generated/`). `site` pairing has not been run.

```python
from discuspdf import read_stru
from discuspdf.fourier_macro import Seed
from discuspdf.mc import MCConfig, MCRunner, Neighborhood, OccupationalTarget, Swap

nn = Neighborhood.from_translations([(1, 0, 0), (0, 1, 0), (0, 0, 1)])     # ±a, ±b, ±c (reverse added)
cfg = MCConfig(neighborhoods=(nn,),
               targets=(OccupationalTarget(0, "Cu", "Au", correlation=-0.3),),
               moves=(Swap(),), seed=Seed((11, 22, 33, 44, 55, 66, 77, 88)),
               moves_per_atom=10, feedback_per_atom=1)
print(cfg.render("mc_in.stru", n_atoms=4096))     # read the macro first
print(cfg.cautions())                             # known engine behaviour that affects this run

runner = MCRunner("runs_mc")                       # launcher: discus_suite (WSL on Windows, see below)
result = runner.execute(runner.prepare(cfg, structure))
result.target_report(tol=0.02)                     # DISCUS's final target vs achieved, 'reached'
result.measure()                                   # the same quantities measured with Package C
result.history(0), result.acceptance()             # feedback trajectory, accepted good/neutral/bad
```

## What DISCUS's MMC does (and what the API makes of it)

| Fact (source + probe) | Consequence in `discuspdf.mc` |
|---|---|
| Acceptance: downhill always; uphill **and ΔE = 0** with `1/(1+e^{ΔE/kT})` (heat bath, not Metropolis; ΔE rounded to 1e-4). Probe: J = 0 → exactly ½; kT → ∞ → ½ of non-downhill moves | stated in every run's `cautions`; choose energies with typical ΔE ≫ 1e-4 |
| `set cyc` counts **valid trial moves**; same-species swap draws are redrawn, not counted | `moves_per_atom × N`; the result must report exactly that many (`Gen`) or the run fails |
| Same 8-value seed + serial → byte-identical; OpenMP → irreproducible and more moves than requested | every macro has `seed` (8 values, required) and `set parallel, useomp:off` |
| `set vec` pairs are directed (origin → target only) | `Neighborhood(symmetric=True)` adds the reverse vectors |
| Default shift σ is 0 | `Shift` requires σ per species |
| `CORR`: energy ignored, PID feedback with damping; scaled ×0.005 for \|c\|<0.1, J = 0 for \|c\|<0.001 | at most one feedback target per run; cautions for small targets |
| Lennard-Jones needs four numbers | always written |
| `set mode` with an atom list sets the wrong probability (bug) | moves never use atom lists |
| `set valid` is a no-op | not offered; `set finish` is offered as `Convergence` (phase 2b, below) |
| `save` drops `ncell`, upper-cases names | `MCRunner.load` restores supercell and spelling |
| A second occupational target on a neighbourhood replaces the first; one displacement direction per neighbourhood | both refused: use separate neighbourhoods |
| Rows are printed by neighbourhood, then energy type, then atom type — not in the order given — and skipped without pairs | rows are matched to targets by (neighbourhood, type, species pair); a missing row is an error |

## Targets and moves

| Class | DISCUS | Energy (units of kT) |
|---|---|---|
| `OccupationalTarget(nb, a, b, correlation=c \| energy=J)` | `corr … CORR/ENER` | J·(N_like − N_unlike) per centre; J < 0 clusters, J > 0 orders |
| `DisplacementTarget(nb, a, b, direction, correlation= \| energy=)` | `cd … dir:[u,v,w]` | J·(u_c·d̂)(u_n·d̂) (Å²), counted only when the moved atom is the vector origin |
| `SpringTarget(nb, a, b, distance, k)` | `spring` | k (d − d0)², averaged over the centre's neighbours |
| `LennardJonesTarget(nb, a, b, distance, depth, n_rep=12, n_att=6)` | `lennard` | minimum −\|depth\| at d0, averaged over the neighbours |
| `Swap(p, pairing)` / `SwapDisplacement(p, pairing)` / `Shift(sigma, p)` | `swchem` / `swdisp` / `shift` + `set move` | `pairing`: all, local, slocal, site; σ in unit-cell fractions |

## Results and diagnostics

* `status` is `complete` only when DISCUS exited 0, printed no error, did all requested moves and wrote the
  structure; otherwise `MCRunner` raises and `status.json` says why. **`complete` does not mean the targets were
  reached**: use `target_report(tol)` (feedback targets get `reached` True/False; fixed-energy targets `None`).
* `measure()` recomputes each target on the final structure, independently of DISCUS's log but with DISCUS's
  definitions: the occupational value as the mean of the two Warren–Cowley α (plus `pooled_alpha`, Package C's
  pooled-θ α, equal for a binary system with symmetric pair counts), the uncentred displacement correlation from
  the site averages with (a→b) and (b→a) pairs pooled, and mean/spread/number of spring and LJ pair distances.
  It reproduces DISCUS's printed values on the probe runs (to their 3 decimals) and a brute-force evaluation of
  DISCUS's formulas on a two-site, two-species displaced crystal (to 1e-12).
* `load()` treats as failed: a nonzero or unknown exit code, an engine error line (warnings are not errors),
  fewer moves than requested, a missing/unreadable output, other species or a different atom count, staged
  inputs changed, or a target without a printed row.
* `replica_summary(results)` gives the seed-to-seed mean and spread of achieved and measured values for runs
  that differ only in the seed.

## Extensions (phase 2b)

Four additions, each read from the DISCUS 6.23.01 source (line references in the docstrings; background in
`docs/MC_FACTS_EXTENSIONS.md`). None has been run in DISCUS yet: the test environment has no engine.

| Feature | Renders | Pitfall |
|---|---|---|
| `RepulsiveTarget(nb, a, b, depth, b_scale=1, c=0, m=1)` | `set target, ic, repulsive, A, B, \|depth\|, b_scale, c, m` | Pairs without a repulsive target are averaged in as −\|depth_min\| (smallest \|depth\| over the run); the printed "target" is DISCUS's internal 100 and is not returned. |
| `BuckinghamTarget(nb, a, b, A, rho, B)` | `set target, ic, bucking, A, B, 0.0, A, rho, B` | DISCUS finds the distance itself by a search from 10 Å: refused unless the minimum is inside (0.5, 10) Å with E < 0 (`buckingham_minimum` reproduces the search). |
| `Shift(sigma, p, directions={sp: (u, v, w)})` | `set move, sp, u, v, w, s` for the listed species | The species needs one positive σ (not a 3-tuple); the vector is not normalised, so its length scales the step. |
| `MCConfig(finish=Convergence(diff=, rdiff=, change=, aver=))` | `set finish, stop:converge, …` right after `set feed` | Tested only at feedbacks, from the 3rd. Offered only for a run with one occupational target given as `correlation=`: every other target, and `energy=` targets, also enter DISCUS's convergence history with targets the test cannot reach (`mmc_basic.f90:1014`, `:1121-1316`, `:2429`). |

The log parser reads repulsive rows (`Repuls.` in the feedback table, `Repulsive` in the final table) and
Buckingham rows. DISCUS prints Buckingham rows without a label and without a target column (format 2100,
`mmc_basic.f90:1325`), so they carry the mean distance only. The convergence history also contains the Hooke,
Lennard-Jones, repulsive, Buckingham and angle targets (`mmc_basic.f90:1121-1316`); `finish` refuses them.

## Running on Windows
DISCUS runs in WSL: `MCRunner(runs_dir, launcher=("wsl.exe", "-d", "Ubuntu-22.04", "--", "discus_suite",
"-noautorun", "-macro"))`; the run directory path must not contain spaces.

## Not covered
Molecules, angle/environment/connectivity neighbourhoods, `unid`, `cn`, `group`, `heli`,
more than one feedback target, parallel runs, partial occupancies (vacancies as a species are untested).
